# 申请、部署与体验版指南

> 本文面向“两个人私用”的体验版场景。微信公众平台入口和套餐规则可能调整，请以页面当时显示为准。

## 1. 注册小程序并获取 AppID

1. 打开[微信公众平台](https://mp.weixin.qq.com/)，注册“小程序”账号。
2. 按页面要求完成邮箱激活、主体选择和管理员核验。
3. 登录后台，在“开发管理 / 开发设置 / 开发者 ID”中复制 AppID。
4. 复制 `project.config.example.json` 为 `project.config.json`，将其中的 `appid` 替换为自己的 AppID。

不要把 AppSecret、登录 token 或带临时凭证的后台链接写入代码或提交到 GitHub。

## 2. 导入微信开发者工具

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 使用小程序管理员微信扫码登录。
3. 选择“导入项目”，项目目录选择仓库根目录。
4. 先编译一次，确认“今天吃什么”和“我们的饭饭心愿”页面正常。

如果暂时没有云环境，可复制 `config.example.js` 为 `config.js`，保持其中的 `dataMode: 'demo'` 预览界面。该模式只使用本机缓存，不能跨手机同步。

## 3. 创建云环境

1. 在微信开发者工具顶部点击“云开发”。
2. 创建环境并复制环境 ID。
3. 在本机 `config.js` 中设置 `dataMode: 'cloud'`。
4. 将 `cloudEnvId` 替换为自己的环境 ID。

`config.js` 和 `project.config.json` 默认不会被 Git 跟踪，真实环境信息只保存在本机。

环境 ID 和 AppID 不是密码；AppSecret 才是服务端敏感凭证，本项目不需要它。

## 4. 部署 `mealWish` 云函数

在开发者工具的云函数目录中找到 `mealWish`，右键选择“上传并部署：云端安装依赖”。部署成功后确认云函数状态为可用。

云函数会：

- 获取调用者真实 `openid`；
- 保存双方各自的心愿；
- 限制最多两个账号提交；
- 防止给自己的心愿点“收到啦”；
- 首次运行时尝试创建 `meal_wishes` 集合。

不要把数据库权限设置为“所有用户可读写”。客户端只通过云函数访问数据。

## 5. 添加另一位体验成员

1. 登录微信公众平台。
2. 在“成员管理 / 体验成员”中添加对方微信号。
3. 在微信开发者工具中上传代码，填写版本号和说明。
4. 在平台“版本管理”中将开发版本选为体验版。
5. 把体验二维码发给已添加的体验成员。

## 6. 双人验收

1. 两个微信号分别提交一次心愿。
2. 双方打开“我们的饭饭心愿”。
3. 每个人都应看到“我的饭饭心愿”和“TA 的饭饭心愿”。
4. 一方点击对方的“收到啦”，另一方应在约 2.5 秒内看到变化。
5. 再点击“可以开饭啦”，确认双方状态一致。

## 7. 当前适用范围

当前权限模型依赖“只有两位体验成员能进入小程序”这一前提，适合情侣或两位家庭成员私用。如果将来公开发布，需要增加配对码、成员解绑、管理员控制、隐私协议和更严格的数据授权。

这个项目不需要：

- 自建云服务器；
- 域名和 HTTPS 证书；
- 微信支付；
- 商家下单、配送或售后能力。
